# Frame photographs

These JPEGs use documentary photographs of two existing exhibits. Landscape exports are 2560 × 1440 and portrait exports are 1440 × 2560. The Frame layout always displays the photographer and licence for these images, including in Artwork only mode.

Current operations are separately supported by the [railway’s timetable](https://brienz-rothorn-bahn.ch/fahrplan-preise/) and [Hovertravel](https://www.hovertravel.co.uk/company/about-hovertravel/).
